## About Me

**Habib Behdarvandi, here.**

I'm a **Computer Engineering student and Full-Stack Developer** focused on building modern web applications with **Next.js, TypeScript, Prisma, and MySQL**.

I enjoy working across the entire development lifecycle — from designing relational database architectures and APIs to building responsive, accessible, and maintainable user interfaces.

My current focus is on improving my backend architecture, system design, database engineering, and deployment skills while gradually expanding toward **cybersecurity and network engineering**.

### What I Do

* Build full-stack applications with **Next.js**
* Design scalable relational databases with **MySQL**
* Build type-safe applications with **TypeScript**
* Design APIs and backend architectures
* Work with **Prisma ORM**
* Create responsive interfaces with **Tailwind CSS & shadcn/ui**
* Design authentication, authorization, and permission systems
* Work with **REST APIs**
* Analyze and optimize database structures
* Deploy and maintain production applications

My goal is simple: **build reliable software, understand the systems behind it, and continuously improve as an engineer.**
